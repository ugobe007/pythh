### Secret sauce — ranked by LP credibility (VC Lab order)

Use the highest true metrics you can stand behind:

1. **Exits / MOIC** — Oracle book has press-verified MOIC examples; treat carefully (selection bias). Prefer a **conservative** line until audited.
2. **Investment performance** — verified funded rate on Oracle picks (e.g. ~44% verified funded at GOD ≥ 70).
3. **Capital raised (for founders)** — only if you have clean, attributable numbers.
4. **Sales closed** — N/A for fund thesis unless GP ops track record.
5. **Companies helped** — e.g. scored universe **11k+**, investment-grade **~1.7k+** (GOD ≥ 70).
6. **Network size** — **6k+** mapped investors / capital graph.
7. **Years of experience** — fill with GP bios (do not invent).

> **Pythiam Ventures is launching an $8MM seed fund in the United States to back US AI and B2B software companies, using Pythh’s signal engine — 11k+ scored startups and Oracle picks with a ~44% verified-funded hit rate.**

## What to tighten before LP meetings

| Open item | Action |
|-----------|--------|
| **Fund size** | Confirm $5–10MM band; don’t pitch $50MM as a first fund |
| **Stage** | Choose **seed** *or* **pre-seed**, not both, in the one-liner |
| **HQ city** | Replace “United States” HQ slot with a city if you have one |
| **Oracle metrics** | Cite date-stamped numbers from [PYTHIAM_VENTURES.md](./PYTHIAM_VENTURES.md); refresh before each LP send |
| **GP secret sauce** | Add 1–2 personal metrics (exits, ARR scaled, years) when ready — LP template ranks those above network size |
| **Legal vs thesis** | Thesis guides allocation; reserve 20–30% flexibility for exceptional outliers |
